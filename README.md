# Own Photo

Расширение для SillyTavern: заменяет сгенерированную (или ещё не сгенерированную) картинку в сообщении **вашим собственным фото** из галереи устройства. Файл получает имя и сохраняется в папку персонажа так же, как обычная сгенерированная картинка.

## Возможности

- Кнопка-камера на каждой картинке с тегом `data-iig-instruction` или `src="[IMG:GEN]"`.
- Выбор фото из галереи или камеры телефона. Сначала открывается галерея, потом окно подтверждения с превью.
- Своё имя файла (по умолчанию `photo_ГГГГММДД_ЧЧММСС`) и подсказка, куда он ляжет.
- Файл загружается в `/user/images/<имя персонажа>/`, `src` в тексте сообщения и в свайпе переписывается на реальный путь, чат сохраняется.
- Остальные атрибуты тега (в том числе `data-iig-instruction`) не меняются: LLM по-прежнему видит ту же структуру, а реальный путь означает «картинка уже есть».
- Большие фото с телефона автоматически уменьшаются (по умолчанию до 2048 px по длинной стороне).
- Интерфейс на русском и английском, цвета берутся из активной темы SillyTavern.
- Подтверждение показывается родным окном SillyTavern, поля ввода не вызывают зум на iOS.

## Установка

### Через SillyTavern

1. Откройте **Extensions → Install extension**.
2. Вставьте ссылку на репозиторий:
   ```
   https://github.com/alicetaeva/own-photo
   ```
3. Нажмите **Install** и перезагрузите страницу.

## Как пользоваться

1. Найдите в чате картинку с тегом генерации (даже ту, что ещё не сгенерирована или завершилась ошибкой).
2. Нажмите на значок камеры в углу картинки. На ПК он появляется при наведении, на телефоне виден всегда.
3. Выберите фото в галерее.
4. В окне проверьте превью и при желании измените имя файла (нажмите на превью, чтобы выбрать другое фото).
5. Нажмите **Заменить**.

Картинка сразу заменится в сообщении. Файл лежит в `/user/images/<имя персонажа>/<имя файла>.<расширение>`.

> Если файл с таким именем в этой папке уже есть, он будет перезаписан. Окно предупреждает об этом.

## Настройки

Открываются в **Extensions → Own Photo**.

| Настройка | Описание | По умолчанию |
|-----------|----------|--------------|
| Показывать кнопку на картинках | Включает и выключает кнопку | включено |
| Положение кнопки | Любой из четырёх углов картинки: сверху или снизу, слева или справа. Поменяйте, если кнопка накладывается на другое расширение | сверху слева |
| Макс. сторона фото | Оригинал, 1024, 1536, 2048 или 3072 px | 2048 |

## Как это работает

1. Расширение следит за чатом и оборачивает подходящие `<img>` в контейнер с кнопкой.
2. После выбора файла он при необходимости уменьшается через canvas. PNG и WebP сохраняются как PNG, остальное как JPEG (качество 0.9). GIF и файлы, которые не нужно уменьшать, отправляются как есть.
3. Файл отправляется на сервер через `POST /api/images/upload` с папкой `ch_name` = имя автора сообщения.
4. В сыром тексте сообщения находится нужный тег (по `data-iig-instruction`, а при совпадении количества тегов по порядковому номеру) и в нём заменяется `src`.
5. Сохраняется чат, вызывается событие `MESSAGE_UPDATED`, чтобы другие расширения узнали об изменении.

Если, пока было открыто окно, сообщение перерисовалось, нужная картинка ищется заново.

## Совместимость

- Работает с тегами формата
  ```html
  <img data-iig-instruction='{"style":"anime","prompt":"..."}' src="[IMG:GEN]">
  ```
  который использует расширение Inline Image Generation.
- Старый текстовый формат `[IMG:GEN:{...}]` не обрабатывается: расширение работает только с `<img>`-тегами.
- Нужна версия SillyTavern, где доступны `SillyTavern.getContext()` и `/api/images/upload`.
- На телефоне форматы вроде HEIC зависят от браузера: iOS обычно сам отдаёт JPEG, а если файл не открылся, выберите JPG или PNG.

## Если что-то не работает

| Симптом | Что проверить |
|---------|---------------|
| Кнопки нет | Включена ли она в настройках, перезагружена ли страница, есть ли у картинки атрибут `data-iig-instruction` или `src="[IMG:GEN]"` |
| Кнопка закрывает или перекрывает другую | Выберите другой угол в настройках (например, снизу) |
| Картинка заменилась, но после перезагрузки вернулась | Появилось предупреждение «тег не найден»: текст сообщения мог быть изменён вручную или макросами. Замените вручную или перегенерируйте тег |
| Ошибка загрузки | Откройте консоль браузера (`[Own Photo]`) и проверьте ответ `/api/images/upload` |
| Галерея не открывается | Браузер мог заблокировать выбор файла: нажмите на кнопку ещё раз, не используя двойной тап |
